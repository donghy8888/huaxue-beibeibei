# 化学背背背 ⚗️

初中化学背背背：用小游戏记住初中化学知识。纯 HTML/CSS/JS，无需构建，手机优先。

👉 **在线玩：<https://donghy8888.github.io/huaxue-beibeibei/>**

## 小游戏

| 游戏 | 玩法 |
| --- | --- |
| 🎯 化合价击毙（元素翻牌） | 简化周期表上的牌依次翻开，用屏幕键盘答出化合价，答对就“击毙”它（射击 + 爆炸动画 + 音效）。限时、计分、连击、结算、最高分、自动记入错题本。 |
| 🔗 元素连连看 | 元素/原子团符号 ↔ 中文名限时配对，清空一版 +5 秒。 |
| 🧩 化学式拼装 | 给出两种成分及化合价（如 Al +3、O −2），从 4 个选项中选出正确化学式（Al₂O₃），并显示名称。 |
| 📒 错题本 | 记录化合价答错的元素/原子团，可一键“只练错题”，练对即移除。 |
| 📜 化合价口诀表 | 口诀 + 全部元素/原子团化合价一览。 |
| 🧪 实验 · ⚡ 现象抢答 | 限时选出实验的正确现象（37 题：C/S/P/Fe/Mg/H₂/CO/CH₄ 燃烧、CO₂ 性质、电解水、CO 还原、金属与盐/酸、指示剂、中和、铁生锈、燃烧条件……），快答加分。 |
| 🧪 实验 · 🕵️ 气体鉴别侦探 | 4 个案子，用带火星/燃着的木条、澄清石灰水、石蕊、点燃罩烧杯等工具鉴别 O₂、CO₂、H₂、CO、空气、N₂、CH₄，工具用得越少奖励越多。 |
| 🧪 实验 · 🧫 虚拟实验台 | 选试剂和仪器做 6 个实验（制 CO₂、H₂O₂ 制 O₂、制 H₂、KMnO₄ 制 O₂、铁钉+硫酸铜、酸碱中和），看动画现象，再答检验方法/化学方程式追问。 |
| 🧪 实验 · 🔧 装置拼装 | 为 4 个制气实验选发生装置 + 收集装置，选错会讲原因（试管口倾斜、液封、排水/排空气法……）。 |
| 🧪 实验 · 🔍 操作找茬 | 16 幅代码绘制的错误操作图，点出错误位置并选出正确改法。 |

首页可调：每局时长（30/60/90/120 秒）、题目范围（元素 / 原子团 / 混合）。右上角可静音。电脑上也能用键盘：`1`–`7` 为正价，先按 `-` 再按数字为负价。

## 化学约定

- 依据口诀：一价钾钠银氢，二价钙镁钡锌，三铝四硅五价磷，二三铁、二四碳，铜汞二价最常见；氧 −2、氟 −1，单质为 0。
- **多价元素答出任意一个常见化合价即算对**，答完会列出全部常见化合价：Fe +2/+3，Cu +1/+2，C +2/+4，S −2/+4/+6，N −3/+2/+4/+5，Cl −1/+1/+5/+7，Mn +2/+4/+6/+7，I −1/+5（KIO₃）。
- Hg 只收 +2，P 只收 +5（按口诀）。
- **稀有气体 He、Ne、Ar** 显示在周期表中（灰色“稀”牌），但不出化合价题，点一下会有说明。
- 原子团：OH⁻ −1，NO₃⁻ −1，SO₄²⁻ −2，CO₃²⁻ −2，NH₄⁺ +1，PO₄³⁻ −3，ClO₃⁻ −1，MnO₄⁻ −1。

实验题答错会进入错题本的“实验错题”，可专项练习现象题和找茬题。

## 如何添加元素 / 原子团

所有化学数据都在 [`data.js`](data.js)：

```js
{ sym: 'Pb', name: '铅', z: 82, row: 6, col: 8, val: [2, 4], main: [2], note: '小贴士' },
```

- `val`：所有可接受的化合价；`row`/`col`：在简化周期表中的位置（列说明见文件顶部注释，别和已有元素重叠）。
- 原子团加到 `GROUPS`，数字会自动显示成下标。
- 化学式拼装题来自 `CATIONS` × `ANIONS`，不想出的组合写进 `SKIP`。

## 如何添加实验题

实验数据都在 [`lab-data.js`](lab-data.js)：`PHENOMENA`（现象题）、`GASES`/`GAS_TOOLS`（气体鉴别结果表）、`BENCH`（实验台）、`DEVICE_*`（装置）、`MISTAKES`（找茬题）。插图在 [`lab-svg.js`](lab-svg.js) 中用 SVG 代码绘制。
